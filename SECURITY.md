# Security

## Supported versions

Only the latest release gets security fixes. Please update before reporting.

## Reporting a vulnerability

Report it privately with GitHub's form: https://github.com/rickysinghmba/openclaw-whisper-server/security/advisories/new

Please don't open a public issue for a vulnerability, and leave real passwords, tokens and private
addresses out of the report.

This plugin sends audio to a whisper.cpp server on the same machine and nowhere else, so reports about anything that could send audio off the machine are especially welcome.

You should get a reply within a week. Fixes are released as a new version, with a note in
[CHANGELOG.md](CHANGELOG.md) and the release notes.
